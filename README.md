# Careline

Локальный Django-прототип медицинского навигатора и аптечного каталога. Он не ставит диагнозы, не назначает лекарства и не вызывает экстренные службы.

## Запуск

```text
.venv/Scripts/python.exe manage.py migrate
.venv/Scripts/python.exe manage.py createsuperuser
.venv/Scripts/python.exe manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Добавляйте аптеки, лекарства, фотографии, профили врачей и рецепты через `/admin/`. Регистрация создаёт пациентский профиль и персональную скидку автоматически. Ассортимент аптеки показывается на её странице `/pharmacies/<id>/` — отдельной страницы каталога `/medicines/` больше нет.

## Врачи

При регистрации выберите роль «Врач» и укажите специальность. Новый профиль создаётся со статусом `OFFLINE` и не показывается пациентам. Администратор проверяет данные в `/admin/` и вручную меняет статус на `FREE`, чтобы опубликовать профиль.

## Корзина и demo-оплата

Откройте страницу аптеки, выберите количество и добавьте лекарство в корзину. В корзине нажмите «Оплатить» — откроется отдельная страница оплаты: слева сводка заказа, справа форма с визуалом карты (номер, срок, имя и CVC прямо на карточке). Заказ создаётся со статусом «Ожидает проверки», оплачивается картой (`payment_method=CARD`) и появляется в `/admin/`. После успешной оплаты показывается экран «Заказ оплачен» с номером заказа, составом и суммой, кнопками «История заказов» и «Вернуться в корзину». Это учебная оплата: банк не подключён, принимается любой номер карты и любой CVC, введённые данные никуда не сохраняются и не отправляются. Ошибка валидации не создаёт заказ и оставляет корзину на месте.

## Фотографии

Загрузите файл в поле фото лекарства через `/admin/` → Medicines. Файл хранится в `media/`; в режиме разработки Django раздаёт его по `MEDIA_URL`. Если фото нет, карточка показывает запасную плашку.

## Gemini

Без ключа работает локальная маршрутизация по ключевым словам. Для выбора специальности через Gemini задайте переменную `GEMINI_API_KEY` в окружении перед запуском сервера. Пользователь должен отдельно согласиться на передачу симптомов. Gemini не используется для диагноза, оценки вероятности болезни или назначения лечения.

## Экстренный блок

`1488` отображается только как демонстрационная подпись и не является ссылкой для звонка. При угрозе жизни интерфейс предлагает обратиться в местную экстренную службу.
